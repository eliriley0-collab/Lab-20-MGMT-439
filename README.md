# Lab 20 submission

This folder collects the files and links for your individual checkout. Keep the paths below when adding files to your Project 2 repository.

| File or link | Status |
| --- | --- |
| [docs/lab20-checkout.md](docs/lab20-checkout.md) | Decision line and saved baseline are filled in. Add your partner’s note, changed-input evidence, and fix or clean-run note. |
| [project2_results.json](project2_results.json) | Saved baseline is included. Confirm it matches your before run. |
| Changed-input output | Add the file from your actual run under its own filename. Link it from the checkout record. |
| Prediction commit link | Paste the link to the commit you pushed before the run into the checkout record. |
| Fixed file and commit link | Include these if you fixed a cold-run failure. If the run was clean, record that no fix was needed. |

Submit the GitHub URL of your completed checkout Markdown and the URLs of the evidence files you used. Record unresolved items in the checkout Markdown.
